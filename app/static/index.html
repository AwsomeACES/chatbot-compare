LOCAL WORKSPACE

Transparent by design.

Configuration and operating boundaries.

Environment configuration

Set upload limits, execution timeout and optional OpenAI credentials in the project's .env file, then restart. Per-run API keys are not persisted or stored in browser storage.

MAX_UPLOAD_MB=50
TEST_TIMEOUT_SECONDS=60
MAX_TEST_CASES=200
OPENAI_MODEL=
OPENAI_API_KEY=

Known MVP limits

No filesystem or network sandbox for uploaded tests. No automatic startup or uploaded dependency installation. No JS/TS execution or coverage. No dependency CVE database audit, tool action verification or population-level fairness conclusions. Subjective evaluations require human review. No fabricated scores or benchmarks.
